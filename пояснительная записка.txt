Это приложение онлайн заметок

При первом заходе на сайт открывается просьба зарегистрироваться.
В верхнем правом углу есть кнопка войти.
После нажатия на кнопку открывается страница логина.

Там есть 2 поля ввода: логин, пароль, а так же гиперссылка на страницу регистрации, кнопка для подтверждения,
кнопка "запомнить меня".

На странице регистрации наполнение аналогичное лишь с разницей, что при нажатии на кнопку, пользователь не входит,
а регистрирует аккаунт.

После входа, открывается главная страница, а вместо "войти" теперь находится логин и иконка, при нажатии на которую
пользователь выйдет из аккаунта.

На ней есть: кнопка добавления заметок, элементы поиска, список заметок.

Каждая заметка имеет несколько отличительных характеристик: папка, тема, заголовок, содержание

При нажатии на кнопку добавления заметок в списке заметок появляется новая записка, которая имеет пустое содержание,
тему "НОВАЯ ЗАМЕТКА", заголовок "Новая заметка", и не принадлежит к папке.

Ниже кнопки идут элементы поиска: фильтр и строка поиска.

Фильтр представляет собой выпадающий список с вариантами выбора из всех существующих у созданных заметок тем.
После выбора темы из списка, в списке заметок будут показываться только заметки с этой темы.

Строка поиска представляет полее ввода. Заметки ищутся по контексту и заголовку.
После ввода какого-то текста в поле, в списке заметок будут показываться только заметки с этим контекстом.

После поиска идет список заметок.
Идут папки, отсортированные в лексикографическом порядке.
В каждой папке, можно увидеть заметки, соответствующие папке.
Все заметки без папки будут отображаться как будто они находятся в папке "Мои заметки".

При нажатии на ЗАГОЛОВОК заметки пользователя переадресует на ссылку с редактированием заметки.
Сверху находятся поля для ввода заголовка, темы папки.

Ниже идет полоска с кнопками: галочка "открыт для просмотра", иконки-кнопки "загрузить", "сохранить", "удалить".
Все изменения применятся только посли нажатия на иконку "сохранить".
Иконка "загрузить" загружает записку в формате .txt
Иконка "удалить" перекидывает на окно подтверждения удаления (на него может попасть только владелец).
Изначально сайт может открыть только владелец, при нажатии на галочку открыт для просмотра (и последующем сохранении)
любой, кто прейдет по ссылке, сможет просматривать заметку.

После полоски с кнопками идет большое поле для написания контеста, содержания, письма.

Примечание 1:
    Из непройденных нами фреймворков я использовал HTMX, который добавляет новые HTML теги по типу class, href и т.п.
    Он позволяет при каком-то событии отправить Get запрос и заменить часть HTML документа на полученный результат.

Примечание 2:
    При нажатии на название сайта перекидывает на главную страницу.

Примечание 3:
    Главный файл - app.py.
